    About these logs

    The AI Use Log plugin for Claude Code saves a copy of each conversation in the project's ai-log folder after every reply Claude gives. Each session is one .jsonl file. A folder with the same name holds the work of any helper agents Claude sent out (for example, by the Superpowers plugin).

    These are the original records Claude Code keeps, but they are ordinary files: they show what happened, and they are not tamper-proof.

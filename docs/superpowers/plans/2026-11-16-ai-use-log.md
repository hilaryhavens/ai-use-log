# AI Use Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code plugin that automatically copies each session's transcript (plus subagent transcripts) into `<project>/ai-log/`, a browser viewer to read those logs, and a student guide covering it and the other recommended features.

**Architecture:** The plugin is a hooks-only plugin. `Stop` and `SessionEnd` hooks call a bash script through a cmd/bash polyglot wrapper (the pattern superpowers uses, MIT), so it runs on Windows (Git Bash) and Mac without other dependencies. The viewer is a static `docs/index.html` on GitHub Pages: a pure parser module (`docs/parse.js`, unit-tested in Node) plus a renderer. The guide follows Hilary's existing guide pattern: Claude Doc master → `src/body.html` → `python src/build.py` → site + Canvas version.

**Tech Stack:** bash, cmd; vanilla HTML/CSS/JS (no build step); Node `node:test` for dev-only tests; Playwright MCP for UI checks; Python build script for the guide.

**Spec:** `docs/superpowers/specs/2026-11-16-ai-use-log-design.md`

## Global Constraints
- Students need nothing beyond Claude Code (and Git Bash, which Claude Code on Windows already requires). No jq, Python or Node at runtime.
- The hook must never block or break Claude: it always exits 0 and prints nothing to stdout.
- Output path: `<project>/ai-log/<YYYY-MM-DD>_<session_id>.jsonl`, plus `<project>/ai-log/<YYYY-MM-DD>_<session_id>/` holding the session's `subagents/` and `tool-results/` folders. Exactly one file per session, overwritten on each copy.
- The viewer uploads nothing and makes no network requests.
- Plugin name `ai-use-log`; marketplace name `ai-use-log`; repo `hilaryhavens/ai-use-log` (public). Install commands: `/plugin marketplace add hilaryhavens/ai-use-log` then `/plugin install ai-use-log@ai-use-log`.
- Guide byline: "Written by Claude and Hilary Havens". Guide sections: habits; Superpowers + Playwright; going further; AI Use Log (required); verifying quotations. No text-encoding, Twine or storytelling sections.

## Review Focus
1. Project path contains spaces (e.g. `OneDrive - University of Tennessee`): the hook must still copy correctly. Owned by Task 1 test `spaces in project path`.
2. Windows backslash paths in the hook's JSON (`C:\\Users\\...`): must resolve via cygpath. Owned by Task 1 test `windows-style transcript_path`.
3. Session date must not change across midnight (the same session keeps its first file). Owned by Task 1 test `reuses existing dated file`.
4. Malformed or unknown transcript lines (Claude Code adds new record types often): the viewer skips them and still renders. Owned by Task 2 test `skips bad and unknown lines`.
5. Tool results containing HTML or `<script>`: they must render as text, never as markup. Owned by Task 3 check `escapes html`.

### Task 2: Transcript parser (`docs/parse.js`)

**Files:** Create `docs/parse.js` (ES module, browser + Node), `tests/parse.test.mjs`, `tests/fixtures/` (small trimmed real-shaped jsonl + agent jsonl + meta.json).

**Interfaces:**
- Produces: `parseSession(text: string, opts?: {name?: string}) -> Session` where `Session = {id, title, cwd, model, start, end, version, steps: Step[], stats: {prompts, filesChanged: string[], commands: number, skills: string[], playwright: number, subagents: number}, skipped: number}`.
- `Step = {kind: 'prompt'|'reply'|'thinking'|'tool'|'note', time, text?, tool?: {id, name, label, detail, result, isError}, children?: Session}`.
- `toolLabel(name: string, input: object) -> string`, `attachSubagents(main: Session, agents: {meta: object|null, session: Session, agentId: string}[]) -> void` (nests via `meta.toolUseId` or the tool result's `agentId`).

- [ ] Step 1: Tests in `tests/parse.test.mjs`:
  - `prompts and replies in order` (meta/`isMeta` user lines and `<local-command-caveat>`/`<system-reminder>`-only lines are excluded from prompts; slash commands shown as `note` "Ran /export").
  - `tool use paired with result`.
  - `labels`: Edit → `Edited chapter2.xml` (basename), Write → `Created …`, Bash → `Ran: <description or first 80 chars>`, Skill → `Used skill: superpowers:brainstorming`, `mcp__plugin_playwright_playwright__browser_navigate` → `Playwright: opened <url>`, `…browser_take_screenshot` → `Playwright: took a screenshot`, other `…playwright…browser_X` → `Playwright: X`, Agent/Task → `Sent a helper agent: <description>`, unknown → tool name.
  - `stats` (filesChanged unique basenames from Edit/Write/NotebookEdit; commands = Bash/PowerShell count; skills list; playwright count).
  - `skips bad and unknown lines` (a non-JSON line and `{"type":"api-request-shape"}` → `skipped` counts the bad line, no throw).
  - `nests subagents` via meta toolUseId.
  - `title` from `ai-title` record, else first prompt (first 60 chars).
- [ ] Step 2: Run `node --test tests/`. Expected: FAIL.
- [ ] Step 3: Implement. Ignore record types other than user/assistant/system(`compact_boundary` → note "Conversation was compacted")/ai-title.
- [ ] Step 4: Run `node --test tests/`, and also parse a real transcript from `~/.claude/projects/C--Users-hhavens1-claude/` with a one-off node command printing stats. Expected: PASS, and sane stats.
